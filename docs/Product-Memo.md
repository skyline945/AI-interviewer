# 研面官 · 预推免物语 —— Product Memo

## 一句话

把「保研预推免面试」做成一场叙事游戏：你攻略一位会深挖追问的 AI 面试官，再用一张「追问树」复盘每一次翻车。

## 问题

预推免面试对保研生是**零容错、高信息差**的关卡：

- 没有地方练习「被追问」——简历上的每一行都可能被顺藤摸瓜，而学生第一次被问懵就是正式面试。
- 市面上的「面试题库 / 押题」只有**标准答案**，练不出**临场抗压**；市面上的「AI 模拟面试」大多只给一句模糊点评，**不给复盘路径**。
- 学生真正缺的不是题目，是**一个敢追问、能告诉他「你这次具体死在哪儿」的陪练**。

## 解法

一个 **galgame 形式**的 AI 面试官 + **追问树**复盘系统。

- **表层是游戏**：面试官有「好感度」曲线，每一轮回答都在改写结局（口头 Offer / 待定 / 淘汰），让练习有**叙事张力**和**再来一局的动机**。
- **底层是训练**：好感度只是皮，真正的分数是四维信号——**信任度 / 认可度 / 匹配度 / 危险值**。其中危险值**只增不减**，对应「面试里说错的话收不回来」的真实压力。
- **复盘是产品**：结束后生成一张**追问树**（每一问 → 追问 → 你当时怎么答的 → 扣分点）、一份**危险点清单**（原话引用 + 为什么踩雷）、一组**策略卡**（STAR、用数据说话、承认边界…），并支持**原地重答**让 AI 重新评分做对比。

一句话的差异化：**别人给答案，我们给追问；别人打总分，我们给翻车回放。**

## 核心循环

```
粘贴简历 → 选方向 → 9 轮追问面试（6 阶段）
   ↑                                    ↓
   └── 原地重答，重新评分 ── 复盘报告（追问树 + 危险点 + 策略卡）
```

学生跑完一圈，会清楚地知道自己「哪里翻了车、为什么翻、下一局怎么改」。

## 为什么这么做能成

1. **先自由作答，不给选项卡**——避免「念答案」的提示之嫌，逼学生先暴露真实水平。
2. **追问铁律**——面试官每轮必须基于学生**真实说的话**追一个 why / how / so-what，这正是真实面试官做的事，也是学生最缺的训练。
3. **危险值只增不减**——把「说错话不可撤销」做成一条机械规则，比任何文案都更有压力，也更诚实。
4. **评分稳定**——规则层（短答、回避词等硬信号）兜底 + LLM-as-judge（温度 0、强制 JSON）软判断，delta 做钳制。合格回答危险值严格为 0，只有矛盾/编造/背稿/回避/偏题才涨危险值，避免「AI 乱扣分」破坏信任。

## AI 怎么用（有效用 AI）

- **面试官**（sonnet，temperature 0.6）：读简历 + 实时对话历史，生成有指向性的追问。
- **评分官**（sonnet，temperature 0，强制 JSON）：四维 delta + 危险信号原话引用 + 一句话点评。
- **复盘生成**：追问树、危险点、策略卡由评分信号**确定性组装**，不依赖额外生成，保证复盘可复现。

关键工程点：本地 deepseek 代理会输出 `thinking` 块抢占输出 token，导致 JSON 被截断——通过**禁用 thinking + 括号配平解析器 + 提高 max_tokens** 三招解决。

## 目标用户 & 场景

- **保研预推免/夏令营考生**（核心）：面试前 1-2 周反复练，重点练「被追问」和「讲清自己的项目」。
- 其次可扩展到求职技术面、考研复试——换题库即可复用同一套追问 + 评分 + 复盘引擎。

## 这 16 小时里我们验证了什么

- ✅ 核心循环跑通：设置 → 追问 → 评分 → 复盘 → 重答，全链路可用。
- ✅ 评分有区分度：LLM 扮演的合格学生 9 轮全过、危险值 0、拿到 Offer；含糊/偏题/矛盾的答案会被正确抓到并涨危险值。
- ✅ 追问质量高：面试官会追「这个 2.3% 相对什么基线」「哪些错误是 CRF 真正修正的」这类只有真实面试官才会问的问题。
