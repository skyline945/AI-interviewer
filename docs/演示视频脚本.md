# 演示视频脚本 · 逐句照读版（3 分钟）

> 核心原则（来自挑战文档）：**前 30 秒决定生死，把 wow moment 放在最前面。**
> 所以本版**先预置好设置页再开录**——按下录制键的第一秒，屏幕就已经是「AI 预判出三个软肋」的状态，而不是空白首页。
> 全程一镜到底，不剪。口播可直接照读。

---

## 开录前准备（预置设置页，关键！）

1. 浏览器打开 `https://minimize-creatures-grand-continental.trycloudflare.com`，缩放 **150%**（Ctrl+滚轮）。
2. 点「示例一 · 智能科学与技术（AI 方向）」→ 简历自动填好。
3. 在「导师主页链接」粘贴 `https://www.cs.toronto.edu/~hinton/` → 点「分析面试官」→ **等画像卡出来**。
4. 点「🔍 扫描简历软肋」→ **等 3 张软肋卡出来**。
5. 确认「隐藏本场评分」**不勾**；手机静音、关弹窗。
6. **停在这个画面，再开始录屏。**

> 现在屏幕是「简历已载 + 导师画像卡 + 3 张软肋卡」的满状态，这就是开场的第一记 wow。

## 第一幕 · 开场 Hook + Wow（0:00–0:22）

【口播 · 照读，语速快一点、有能量】
> 保研面试，第一次被追问，就是正式面试。这是**研面官**——看，我还没开口，它已经站在面试官的角度，**预判出我简历里三个会被撕的软肋**。

（鼠标在 3 张软肋卡上逐个划过，停 1 秒）

> 我还贴了导师主页，它抓出研究方向、补全真实论文，追问会往这靠。

（鼠标指画像卡）

> 右上角这个「危险值」只增不减——面试里说错的话，收不回来。开始。

【操作】点「开始面试」。

## 第二幕 · 面试（0:22–1:35）

【进场，指 HUD】
> 四维分数：信任度、认可度、匹配度、危险值。我们正常答第一问。

### 第 1 问（开场·固定题）
> 面试官问：「用一分钟介绍你自己，为什么想读研、想做什么方向。」

【操作】输入框**打出**（照打，短一点打字快）：
```
老师好，我是智能科学与技术专业的本科生，GPA 3.7。做过基于对比学习的病理切片分类，用 SimCLR 把准确率从 82% 提到 89%。想读研，做深度学习加医学影像。
```

【口播】答得具体、有数字，危险值不动。

### 第 2 问（简历深挖·AI 生成）★ 核心 wow
> 面试官追问你简历里的项目——大概率就是刚才那个软肋。

【操作】**先停 5–8 秒完全不动**（犹豫计时跳起来），再打出（照打）：
```
嗯……当时主要就是调了一些超参数，准确率就上去了，具体哪个参数起的作用，我也说不太清。
```

【口播 · 这里放慢，重点】
> 注意左上角的**犹豫计时**——我在故意犹豫，超过 20 秒变黄。
> 这个回答很含糊，看，**危险值涨了**。这正是产品要抓的：逼你正视「想太久、说不清」。

### （可选，时间够再做）第 3 问 · 专业抽查贴画像
> 若 3 分钟有余量，再答 2–3 轮到「专业抽查」，展示问题贴着 Hinton 方向出。不够就跳过，口播带过：
> 「因为贴了 Hinton 主页，后面的专业抽查会往他的研究方向靠，而不是固定八股。」

【操作】点「提前结束并复盘」。
【口播】提前结束，看复盘。

---

## 第三幕 · 复盘（1:35–2:20）

【操作】从上往下滚，逐块停。

【口播 · 照读】
> 结局卡：口头 Offer / 待定 / 淘汰，一句人格化评语。
> **追问树**：每一问 → 追问 → 你当时怎么答的 → 扣分点，整条链路回放。
> **危险点清单**：原话引用 + 为什么踩雷。刚才那句「具体我也说不太清」，被原话抓出来了。
> **策略卡**：STAR、用数据说话、承认边界，教你下一局怎么改。
> 还能**原地重答**——同一道题重新答，AI 重新评分。这是训练，不是考试。

【操作·可选】点一次「原地重答」，打附录 A 的好答案，看分数变化。

## 第四幕 · 收尾（2:20–2:50）

【口播 · 照读】
> 一句话差异化：**别人给答案，我们给追问；别人打总分，我们给翻车回放。**
> 我们的取舍是：不做题库、不做语音，只把「被追问」和「翻车复盘」这一件事做深。
> 学生跑完一圈，会清楚知道自己哪里翻了车、为什么翻、下一局怎么改。

## 附录 A · 备用答案

**原地重答的「好答案」**（把翻车句换成具体、有数字的版本，按面试官实际问的题套）：

> 这个我来说具体点。当时数据集只有两千张标注图，我先做错分样本分析，发现主要过拟合在少数类；于是加随机裁剪和颜色抖动增广，温度系数从 0.5 调到 0.1，投影头加一层。最后 top-1 从 82% 到 89%，其中数据增广贡献约 +4 个点，温度系数约 +2 个点，是我一步步消融出来的。

**专业抽查（梯度消失）扎实答案**（录到专业阶段用）：

> 深度网络里梯度通过反向传播逐层连乘，层数深时连乘因子都小于 1，梯度指数级衰减，前面的层学不动，就是梯度消失；反过来大于 1 就爆炸。缓解：换 ReLU、加残差连接、BatchNorm、合理初始化。

## 附录 B · 卡住了怎么办

- **画像卡没出来/报错**：换纯文本主页链接重试，或跳过这步（口播「支持贴导师主页，这里不展开」），不影响主体。
- **软肋卡只出 1–2 张**：正常，口播「扫出了几个最容易被撕的点」。
- **翻车没涨危险值**：把答案改更含糊（「记不太清」「可能就是」），或停顿更久。
- **点错**：不用剪，说一句「我重来一下」再点，评委能理解。
