# 演示视频脚本（3 分钟）

> 目标：让评委在 3 分钟内看懂「痛点在哪儿 → 我们怎么解 → 差异化是什么」。
> 全程用真实产品录屏，不 PPT；旁白可以后期配，也可以边录边讲。

## 分镜总览

| 时间 | 段落 | 一句话要点 |
|---|---|---|
| 0:00–0:20 | 开场 | 预推免面试零容错，没人陪你练「被追问」 |
| 0:20–0:55 | 设置 | 拖 PDF 简历 → 选方向 → 贴导师主页 → 简历软肋扫描 |
| 0:55–2:05 | 面试 | 9 轮追问，展示追问铁律 + 犹豫计时 + 危险值 HUD |
| 2:05–2:40 | 复盘 | 追问树 + 危险点清单 + 策略卡 + 原地重答 |
| 2:40–3:00 | 收尾 | 差异化一句话 + 地址 |

---

## 0:00–0:20 开场（20s）

**画面**：打开产品首页，标题「研面官 · 预推免物语」。

**旁白**：
> 保研预推免面试，是零容错、高信息差的关卡。你简历上写的每一行，都可能被老师顺藤摸瓜，而大多数人第一次被连续追问，就是正式面试。
> 市面上的题库只给标准答案，练不出临场抗压；市面上的 AI 模拟面试，大多只给一句模糊点评。
> 我们做的，是一个会深挖追问的 AI 面试官，外加一张能告诉你「这次具体死在哪儿」的追问树。

---

## 0:20–0:55 设置（35s）

**画面 + 旁白**（边操作边讲）：

1. **拖入 PDF 简历**（2s）——「先拖一份简历，PDF 直接识别，不用手打。」
2. **选报考方向**（2s）——「选方向，决定专业抽查的题库。」
3. **粘贴导师主页链接**（5s）——「如果你有心仪的导师，把 TA 的主页贴进来。我们会爬取主页、生成面试官画像，再用 OpenAlex 补全 TA 的真实论文——这样追问就会往 TA 的研究方向靠。」
   - 停顿展示画像卡：研究方向 / 风格 / 近期论文。
4. **点「扫描简历软肋」**（10s）——「点一下这里，AI 会站在面试官的角度，预判 TA 会从哪撕你。」
   - 展示 3 张软肋卡：「软肋 / 为什么可疑 / 会怎么追问」。
5. 点「开始面试」。

---

## 0:55–2:05 面试（70s）

**画面**：进入面试，面试官头像 + 好感度/四维 HUD。

**旁白 + 关键点**：
1. （10s）「面试共 6 阶段 9 轮。注意右上角的危险值——它只增不减，对应『面试里说错的话收不回来』。」
2. （20s）演示一轮「简历深挖」：面试官追问「为什么用这个方案」「这个 2.3% 相对什么基线」——**点出这是追问铁律**：「它每轮都基于你真实说的话，追一个 why / how / so-what。」
3. （10s）**故意迟疑作答**，让左上角「犹豫计时」跳到 20s+ 变色——「它在给你计时，让你知道自己犹豫了多久。」
4. （20s）演示一轮「专业抽查」，问题锚在导师的研究方向上——「因为贴了导师主页，这道专业题会围绕 TA 的论文出，而不是固定八股。」
5. （10s）答完，四维分数跳动、危险值涨了一点——「一次含糊的回答，危险值就涨了。」

---

## 2:05–2:40 复盘（35s）

**画面**：面试结束，进入复盘报告。

**旁白 + 关键点**：
1. （8s）结局卡 + 总评：「口头 Offer / 待定 / 淘汰，一句话点评。」
2. （10s）**追问树**：「这是追问树——每一问 → 追问 → 你当时怎么答的 → 扣分点，整条链路回放。」
3. （8s）**危险点清单**：「危险点清单，原话引用 + 为什么踩雷。」
4. （9s）**原地重答**：「点『重答』，同一道题重新答，AI 重新评分做对比——这是训练，不是考试。」

---

## 2:40–3:00 收尾（20s）

**画面**：回到首页或一个总结屏。

**旁白**：
> 一句话的差异化：别人给答案，我们给追问；别人打总分，我们给翻车回放。
> 学生跑完一圈，会清楚地知道自己「哪里翻了车、为什么翻、下一局怎么改」。

## 录制建议

- **时长**：严格控制在 3:00 内，建议 2:45–2:55 收尾，留一点缓冲。
- **口播**：边录边讲比后期配音更自然，也更快；讲错一小段就整段重录，不要剪。
- **节奏**：操作和旁白同步，每个画面停留至少 2s 让评委看清。
- **清晰度**：浏览器缩放 125%–150%，字号放大，别让评委眯眼看小字。
- **提交**：导出 1080p MP4，与 URL、Memo、GitHub 一起邮件发 `mlic@pku.edu.cn`。
